数据与口径

开头连续的 0 与空缺不绘制，从首次正数开始。此后的 0 保留，按本次研究口径表示倒闭；末次为 0 标为“已倒闭”，并记录首次归零年份。如归零后又出现正数，则标为“曾归零后恢复”。NA、N/A 和空白按缺失处理，不补 0、不算倒闭。

所有曲线使用实际门店数。总览前两种视图为线性纵轴；全品牌展开按 ln(门店数+1) 压缩纵轴，刻度仍为实际店数，相同高度差不代表相同增量。分图可各自缩放或统一尺度。圆点为观测值，直线连接相邻年份；跨缺失年份的虚线不代表补值，可切换为断线。曲线停在末次有效记录。

回落幅度 =（历史峰值 − 末次有效值）÷ 历史峰值。峰值重复时列出全部年份。死亡谷分析按全体有数据品牌计算，不随当前选择或年份裁切变化；区间下限含、上限不含。各组使用各自样本数作分母。分组依据是已经观察到的历史峰值，会受样本选择与记录长度影响，因此不能把组内收缩占比理解为行业失败概率。

Pluto 型是“平台后下滑”的工作分类：平台至少包含连续 3 个年度且无缺年；（平台最高值 − 最低值）÷ 最高值 ≤10%；平台最低值 ≥全表峰值的 80%，并比此前某次记录至少高 50%；末次值较平台最高值低至少 20%，且平台后没有再超过该高点 10% 以上。若有多个合格区间，优先展示最长、其后选较晚者。这是数值形态识别，可与严重收缩类别重叠，并不解释经营原因。

“后期缺数据”表示最后有效记录早于 2026，不视为倒闭。2026 沿用源表标签，未注明是否全年或具体截至日期。所有数据基于 Summary Table。HTML 可离线使用，可保存当前视图或导出带形态分类的年度底表。

04 / SCALE & CONTRACTION

规模，能解释品牌收缩吗？

先看底表实际发生了什么，再检验：只知道期初店数，能否更好地估计下一期的收缩。

品牌等权 · 本项目底表

实际发生 vs 模型估计

每行一个期初规模组，比较同一组品牌的两种比例。

实际比例模型估计

实心点 = 事件品牌数 ÷ 本组有效品牌数；空心点 = 本组各品牌模型概率的平均。灰线仅连接两者差距；样本少的组请结合分子、分母阅读。

考虑规模，预测更好吗？

每次拿出一个品牌，用其余品牌拟合，再预测被拿出的品牌。

验证分数怎么算？

Brier 分数 = 所有品牌「预测概率 − 实际结果（0 或 1）」的平方平均，越低越好。模型与基准都不使用被拿出品牌的结果；基准给它的概率是其余品牌的整体事件比例。

这是同一观察期内的留一验证，不是对未来年份的验证。品牌间可能有共同的经营环境影响；本表也不代表全部咖啡品牌。分组拟合接近实际，不等于预测一定有效。

从底表到图表，怎么算？

展开模型公式与展示规则

参数 a、b 通过本期品牌记录的最大似然估计得到：使 Σ[y×ln(p) + (1−y)×ln(1−p)] 最大。模型只用 ln(期初店数) 一个解释变量；不加入参考页的参数、插值点或虚构记录。

本页采用单调的 Logistic 关系，不能识别“中间规模风险最高”的非单调死亡谷，也不识别规模的因果作用。组间实际比例若有起伏，应结合样本量阅读，不能由这条模型推出安全门槛。

保守展示规则：有效品牌至少20个，事件与非事件各至少5个；否则保留实际比例，不输出模型。该门槛是本页的展示取舍；尺度无变化、参数分离或求解不收敛时也不输出估计。缺失不当作0；期末明确记录为0才计作归零。
